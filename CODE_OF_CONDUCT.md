# Code of conduct

- Be respectful. Criticise code and ideas, not people.
- No harassment, insults or discrimination of any kind.
- Assume good intent, and explain your reasoning.
- Keep discussion on the project.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders.

To report a problem, use GitHub's "Report content" option on the comment or issue.
